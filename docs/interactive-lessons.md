# الدرس كتجربة تعلم

`LessonDetails.blocks` تسلسل لوحدات تفاعلية محفوظة داخل `lessons.structure`. لا تُحذف حقول الدروس السابقة ولا تُستبدل قواعد البيانات. الدروس القديمة تقرأ `blocks: []` افتراضيًا، وتحديث API قديم لا يرسل الحقل يحافظ على وحداته الحالية. يمكن إنشاء درس من الوحدات فقط دون مقدمة شرح إضافية، لكن لا يمكن حفظ درس بلا شرح وبلا وحدات.

## الوحدات المتاحة

| النوع | دور الطالب | إعداد الإدارة |
| --- | --- | --- |
| شرح قصير | قراءة خطوة ضمن التسلسل | عنوان ونص |
| استكشف وقارن | التنقل بين الأفكار بالضغط أو الأسهم | 2–6 أفكار وعناوين وشروح |
| بطاقات اكتشاف | تفسير المصطلح ثم كشف معناه | 2–8 بطاقات |
| سؤال وموقف | اختيار قرار ومراجعة تفسيره وإعادة المحاولة | سؤال وثلاثة اختيارات مختلفة وإجابة وتفسير |
| رتّب الخطوات | نقل الخطوات بالأزرار ومراجعة الترتيب | 3–6 خطوات بالترتيب الصحيح وتفسير |
| معمل تفاعلي | تغيير مقاومة/تكرارات/مجموعات، أو مقارنة سيناريوهات استشفاء | اختيار المعمل وتمهيد مرتبط بفكرة الدرس |

المعامل الحالية تخص التدريب الرياضي. بقية الوحدات قابلة للاستخدام في أي مادة بمحتواها الخاص. إضافة معمل جديد تحتاج مكوّنًا موثوقًا واختبارًا؛ لا تقبل الشاشة JavaScript أو HTML من المؤلف.

`validateLessonBlocks` يتحقق على الخادم من الأنواع والأعداد والأطوال والاختيارات والمعرّفات الفريدة. الحد 64 مقطعًا و48 ألف حرف للوحدات مجتمعة، داخل حد طلب API الحالي. كل النصوص تعرضها React كنص آمن. معرّفات DOM الخاصة بالتبويبات والرسوم تُشتق من كل نسخة للمكوّن لتجنب التضارب بين المعاينات.

المحرر يسمح بالإضافة والترتيب والنسخ والحذف والمعاينة الحية. الحفظ والنشر يستخدمان صلاحيات الدرس ومساره القائمة. السؤال والترتيب تدريب بدون درجات، وحالتهما داخل الزيارة الحالية؛ إكمال الدرس يُحفظ على الخادم بالآلية السابقة وبشكل مستقل لكل طالب. لا ندعي أن الضغط على الإكمال يقيس مشاهدة الفيديو أو إتقان المعمل. الاختبارات المحسوبة تظل في قسم الاختبارات.

الوحدات تدعم RTL، شاشات 320 بكسل، الوضع الداكن، لوحة المفاتيح و`prefers-reduced-motion`. تشغيل حركة الأثقال اختياري. منحنيات الاستشفاء نماذج مفاهيمية بلا قيم قياس أو أوقات تدريب مقترحة، وحاصل المقاومة × التكرارات × المجموعات يصف كمية العمل في المثال، دون استنتاج النبض أو النتائج الرياضية منه.

## المثال الجاهز

`/experience/training` تجربة عامة مفتوحة تعرض الوحدات السبعة دون حساب. الوصول إليها متاح من الصفحة الرئيسية، وهي لا تسجل إنجازًا في حساب الطالب. داخل المقرر تظل صلاحيات الدرس وتسجيل الإكمال كما هي.

`lib/training-experience.ts` تجربة أصلية قصيرة بعنوان «من تمرين عشوائي لخطة لها معنى»، تضم سبع وحدات، ويمكن للمحرر إضافتها وتعديلها. ليست بديلًا عن كتاب أو تحويلًا كاملًا للفصول الأربعة. تستلهم أنماط العرض من [المدخل للتدريب](https://ss.seif4d.com/T2/Training/Summaries/CH1)، [الحمل](https://ss.seif4d.com/T2/Training/Summaries/CH2)، [تقنين الحمل](https://ss.seif4d.com/T2/Training/Summaries/CH3)، و[الراحة](https://ss.seif4d.com/T2/Training/Summaries/CH4). تعريف الفرق بين الحمل الخارجي والاستجابة الداخلية يوافق [بيان اللجنة الأولمبية الدولية عن الحمل في الرياضة](https://doi.org/10.1136/bjsports-2016-096581).

لإضافتها مرة في مقرر مبادئ التدريب الرياضي للفرقة الثانية، الترم الأول، للبنين والبنات:

```sh
node scripts/create-training-experience.cjs
```

ينشئ مسودتين، ويحافظ على أي نسخة موجودة وتعديلات الإدارة عليها. `--publish` ينشر النسخ الجديدة عند إنشائها صراحةً؛ لا يغيّر حالة النسخ الموجودة. لا يُضبط الأمر كخطوة تلقائية بعد كل نشر.

اختبار `check-interactive-lessons.cjs` يتحقق من التأليف والحفظ والمعاينة والنشر والصلاحيات، وتفاعلات الطالب والقراءة الآمنة والتخطيطات والحركة المخففة، والحفاظ على الوحدات مع العملاء القدامى. اختبارات الحاوية تتحقق من أداة إنشاء المثال واستمراره مع قاعدة البيانات الدائمة.

## استوديو الكتابة

صناعة الدروس وتعديلها في صفحات مستقلة من إدارة المحتوى. قائمة `/` تضم 25 أمرًا ضمن الكتابة والتنسيق، التفاعل والتطبيق، والوسائط والمراجع، مع بحث عربي وإنجليزي والتنقل بالأسهم وEnter وEscape.

مقاطع الكتابة الجديدة: عناوين بمستويين، قوائم نقطية ومرقمة، قائمة مراجعة، تنبيه بأربعة ألوان، اقتباس، فاصل، محتوى قابل للطي، جدول قابل لتعديل الصفوف والأعمدة، فيديو YouTube وبطاقة مرجع HTTPS. المعاينة وصفحة الطالب تستخدمان نفس المكوّنات. قائمة المراجعة تتابع الاختيارات داخل الزيارة ولا تسجل درجات. الفيديو لا ينشئ iframe قبل ضغط التشغيل.

- `Enter`: فقرة جديدة؛ `Shift + Enter`: سطر داخل الفقرة؛ `Ctrl / ⌘ + Enter`: فقرة بعد المقطع الحالي.
- `## ` أو `### `: عنوان؛ `- ` أو `1. `: قائمة؛ `> `: اقتباس؛ `[] `: قائمة مراجعة؛ `---`: فاصل.
- Enter مرتان في آخر القائمة للعودة للكتابة العادية. Backspace في أول فقرة يدمجها بالفقرة السابقة إن سمحت حدود النص.
- لصق نص تفصله أسطر فارغة ينتج فقرات مستقلة. تجاوز الحدود يرفض اللصق دون تغيير المحتوى الحالي.
- تراجع وإعادة للمقاطع حتى 40 خطوة، مع دمج الكتابة المتصلة في خطوة واحدة. الاختصار `Ctrl / ⌘ + Z` و`Ctrl / ⌘ + Shift + Z`، أو `Ctrl + Y`. السجل محلي للجلسة، والحفظ صريح بـ`Ctrl / ⌘ + S`.

هياكل بداية للشرح والمراجعة ومثال تفاعلي متاحة في المستند الفارغ. وضع التركيز يخفي شريط سياق المادة ولوحة الإعدادات دون تغيير البيانات. الجداول من عمودين إلى خمسة و1–12 صفًا. لا تُقبل روابط JavaScript أو HTTP أو روابط بيانات دخول، وفيديو YouTube يتحقق من النطاق ومعرّف الفيديو قبل إنشاء رابط تضمين ثابت.

`check-writing-blocks.cjs` يغطي الأوامر والكيبورد والتراجع واللصق والجداول، الحفظ وإعادة الفتح، التفاعلات المنشورة، والتحقق من الروابط والبيانات وشاشات الهاتف.

## الصفحة الرئيسية لإدارة المحتوى

`/admin/content` تجمع الدروس، المواد والوحدات، وخريطة التأليف في تبويبات مستقلة تدعم الأسهم وHome وEnd. تبويب الدروس هو البداية الافتراضية؛ العودة من الاستوديو بسياق مقرر تفتح وحداته. اختيار التبويب وطريقة العرض يُحفظ في `section` و`layout` بالرابط باستخدام History API المتكاملة مع Next، وتفتح اختصارات المواد المقرر المقصود عبر `courseId`.

الإحصاءات وأرقام المنشور والمسودات من البيانات الفعلية، ويمكن ضغطها لتصفية قائمة الدروس. بطاقة الاستكمال تفتح أحدث مسودة حسب آخر تعديل. الفلاتر تدعم المسار ونوع الدرس بما يشمل فيديو YouTube داخل المقاطع. يمكن عرض الدروس قائمة أو بطاقات، وطي المجموعات، والتحديد والنشر الجماعي بالتحقق السابق من الصلاحيات وتعارض التعديلات. التنقل بين التبويبات يحتفظ بالفلاتر والتحديد أثناء الزيارة، بينما تحديث الصفحة يعيد فلاتر البحث للوضع الافتراضي.

اختبار `check-content-dashboard.cjs` يغطي المقاييس والمرشحات والأقسام والكيبورد واستمرار العرض بالرابط واختصارات المواد والاستكمال وشاشات 320–1440 بكسل، بالإضافة إلى اختبارات إدارة المحتوى والوحدات القائمة.
