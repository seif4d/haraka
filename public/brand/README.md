# شعار حركة

- `harka-logo.svg`: الشعار الكامل للأسطح الفاتحة.
- `harka-logo-inverse.svg`: الشعار الكامل للأسطح الداكنة.
- `harka-mark.svg`: علامة النبضة للأيقونات والمقاسات الصغيرة.
- `app/icon.svg` و`app/apple-icon.png`: أيقونات المتصفح والشاشة الرئيسية.

الألوان: أخضر فاتح `#C6F77B`، حبر أخضر `#17291D`، وأبيض دافئ `#F4F8ED`. الكتابة العربية والإنجليزية محوّلة لمسارات SVG، لذلك تُعرض دون تحميل خط أو اتصال خارجي. النص مستمد من Alexandria المحفوظ بالمشروع؛ ترخيص SIL Open Font License في `public/fonts/OFL.txt`.

المكوّن المشترك `components/brand-logo.tsx` يستخدم النسختين المناسبتين للواجهة. اترك مساحة حول الشعار ولا تضغط نسبه؛ استعمل العلامة وحدها عند عدم كفاية المساحة للشعار الكامل.
